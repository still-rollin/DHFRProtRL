# Figures

- `dhfr_oracle_*.png` and `medium_ckpt_scatter.png` plot the oracle against all 4,161 variants.
- `ablation_*.png`, `gravy_*.png` and `instability_*.png` come from single runs per setting; GRAVY and the instability index are sequence-level properties.
- `dhfr_medium_*.png` summarize one earlier checkpoint-testing session.
- `calibration_debug.png` is from the oracle calibration work.
- `experiments/` holds the three figures used in `docs/experiments.md`, drawn by `analysis/experiments_figures.py` from `results/experiments/*.csv`.
